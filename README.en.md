# 3D Portfolio

This is a WebGL-based 3D personal portfolio website, an interactive webpage designed to showcase personal works and project experience.

## Features

- **3D Scene Display**: Immersive 3D scene integrated with Three.js implementation.
- **Work Showcase Grid**: Responsive work display layout supporting category filtering.
- **Carousel Showcase**: Spotlight-style carousel display for selected works.
- **Loading Animation**: Elegant loading interface featuring a progress bar and instructions.
- **Responsive Layout**: Adaptive responsive design catering to different screen sizes.

## Project Structure

```
├── index.html          # Main page file
├── assets/
│   ├── images/         # Image resources
│   ├── models/         # 3D model files (.fbx)
│   └── video/          # Video resources
```

## Main Functionality

- 3D scene browsing and interaction
- Work category display and filtering
- Featured works carousel showcase
- Detail modal view
- Smooth page transition animations

## Tech Stack

- HTML5
- CSS3
- JavaScript (ES6+)
- Three.js (3D Rendering)
- WebGL

## Usage

1. Open the `index.html` file directly in a browser
2. Or run using a local server (e.g., Live Server)

```bash
# Example: Start a simple server using Python
python -m http.server 8000
```
