

# 3D Portfolio

这是一个基于 WebGL 的 3D 个人作品集网站，展示个人作品和项目经验的交互式网页。

## 特性

- **3D 场景展示**：集成 Three.js 实现的沉浸式 3D 场景
- **作品展示网格**：响应式作品展示布局，支持分类筛选
- **轮播展示**：精选作品的走马灯效果展示
- **加载动画**：带有进度条和提示的优雅加载界面
- **自适应布局**：适配不同屏幕尺寸的响应式设计

## 项目结构

```
├── index.html          # 主页面文件
├── assets/
│   ├── images/         # 图片资源
│   ├── models/         # 3D 模型文件 (.fbx)
│   └── video/          # 视频资源
```

## 主要功能

- 3D 场景浏览与交互
- 作品分类展示与筛选
- 精选作品轮播展示
- 详情弹窗查看
- 流畅的页面过渡动画

## 技术栈

- HTML5
- CSS3
- JavaScript (ES6+)
- Three.js (3D 渲染)
- WebGL

## 使用方法

1. 直接用浏览器打开 `index.html` 文件
2. 或使用本地服务器（如 Live Server）运行

```bash
# 示例：使用 Python 启动简单服务器
python -m http.server 8000
```
